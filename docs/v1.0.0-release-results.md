The 16-entry unified and 11-entry Windows defaults include no private drafts,
unreleased course assignments, student records, credentials, fixtures, tests,
source dependencies or instructor tools. The source archive retains the offline
GUI and schemas. Instructor-published v1/v2 S01–S12 JSON is supplied separately.

Follow [the Apache packaging guide](../release/README.md). Back up both live
editions, stage outside the web root, and **preserve every existing assignments/
file, including manifest.json**. Never copy an empty bootstrap manifest over a
live manifest; never mirror/delete the directory. Upload Lite's six JS assets
and then index.html; upload 3D hashed assets, LICENSES/build-info and then index.
Keep older hashed assets until cached pages expire. Test each independent nested
URL and published unit list, comparing live assignment hashes with the backup.
No automatic deployment or upload is implemented.

On Windows, fully extract the standalone ZIP and keep `dist/` beside
`Start-Showcase.cmd`; double-click and leave its PowerShell 5.1 window open.
The loopback HTTP server needs no installed Node/Python. Use graphics-accelerated
Chrome/Edge with WebGL 2 for 3D. Close the window/Ctrl+C to stop. The unified
Apache ZIP requires HTTP(S); file:// loading is unsupported. YouTube/Google Forms
require Internet, and published static JSON exposes answers. No backend,
student tracking, submission management, numerical Intel performance or Safari
compatibility claim is added. Hosted Windows checks verify launcher/HTTP, not a
new physical GPU test. Instructor hardware acceptance is reported separately.
